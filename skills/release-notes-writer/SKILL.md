# Release notes writer

Turn engineering change records into accurate, user-focused release notes without inventing behavior.

## Status

Scaffold only — not ready for use.

## Planned

- Collect changes from PRs, commits, tickets, or pasted notes for a given range
- Filter internal-only changes and group the rest by type and user impact
- Write each entry around what changed for the user and what they need to do
- Call out breaking changes, deprecations, and migration steps prominently
- Link each entry to the relevant docs page
