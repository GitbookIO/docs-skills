# Style guide builder

Infer a style guide from evidence in the docs, then interview the team to fill in what the docs cannot reveal.

## Status

Scaffold only — not ready for use.

## Planned

- Sample pages across content types and extract conventions (voice, person, tense, headings, lists, code, UI text, links)
- Report each convention with evidence and how consistently it is followed
- Turn inconsistencies into explicit decisions with examples of each option
- Ask about audience, tone, reading level, and other intent the docs cannot show
- Produce a draft style guide with numbered, citable rules
