# Information architecture review

Evaluate how a docs set is organized for findability and recommend changes that a team can apply incrementally.

## Status

Scaffold only — not ready for use.

## Planned

- Map the navigation tree, such as SUMMARY.md, sidebars, or folder structure, and page content types
- Find duplicate or overlapping pages that answer the same question
- Find orphaned pages and pages that are hard to reach
- Identify missing content for key user tasks
- Propose a target structure with a migration and redirect plan
