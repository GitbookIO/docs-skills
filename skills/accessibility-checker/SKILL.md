# Accessibility checker

Find content-level accessibility problems that writers can fix in Markdown, separate from site theme or platform issues.

## Status

Scaffold only — not ready for use.

## Planned

- Check images for missing, empty, or filename-style alt text and draft better alt text from context
- Check heading hierarchy and descriptive link text
- Flag instructions that rely only on color, position, or images
- Flag complex tables, unexplained abbreviations, and dense passages
- Report issues by page with concrete fixes
